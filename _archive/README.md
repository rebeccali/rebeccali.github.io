# Archived posts

Retired blog posts from the 2015–2025 version of rebecca.li, kept for history.

Jekyll ignores directories that start with `_` (other than the ones it knows about),
so nothing here is built or published. The images these posts reference still live in
`/img/`.

To bring one back, move it into a `_posts/` directory and re-add a post layout —
none currently exists.
